Scoring methodology.

Transparent weights, fixed reference points, and explicit assumptions.

MODEL SETTINGS

Fixed benchmarks

The original case study normalized amounts to the highest merchant in a group of 20. This standalone tool uses fixed, editable reference points, so the same merchant always receives the same score.

€
€
PPC scoremin(PPC ÷ benchmark, 1) × 35
Revenue scoremin(revenue ÷ benchmark, 1) × 10
Important ceiling: Activity Status is allocated 25 points, but the original micro-rules allow at most 23 points for a logically consistent merchant. The practical maximum of this exact model is therefore 98/100. No silent adjustment has been made.
